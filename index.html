Features

One project, multiple platforms.

The emulator is built around a shared core, with native frontends and graphics backends for each supported platform.

01

Metal

Metal is used on iOS, iPadOS and macOS.

02

Vulkan

Vulkan is planned for Android, Windows and Linux.

03

GamePad

Touch and controller input are built around the Wii U GamePad.

04

Shared core

The emulator core is kept separate from the platform-specific UI.

FAQ

FAQ

Common questions about WiiUlator.

When will WiiUlator be released?

There isn't a release date yet. The project is still being developed.

What devices will it support?

The project is planned for iOS and iPadOS 16.0 or later, macOS, Android, Windows and Linux.

Which graphics APIs will it use?

Apple platforms will use Metal. Vulkan is planned for Android, Windows and Linux.

Will it be on the App Store?

That's the plan for the normal iOS and iPadOS App Store build. Development and testing builds may be distributed separately.

Do I need to provide Wii U system files?

Some Wii U system software may be needed for emulation. WiiUlator will not bundle Nintendo's proprietary system files with the project.

Will games be included?

No. WiiUlator does not include copyrighted Wii U games. You should only use games and files you are legally entitled to use.

Is WiiUlator open source?

Yes. WiiUlator's own code is released under GPL-3.0-or-later.
